Como o MS Project Calcula o Previsto e o Realizado (Regra 0/100 com Peso de Pacotes) No MS Project com EAP ponderada e regra 0/100: Avanço Realizado do Pacote ( Real P ​ ): Cada atividade filha só admite dois valores: 0% (Não iniciado ou Em andamento) ou 100% (Concluído). O progresso do pacote é a proporção de tarefas concluídas: Real P ​ = N P ​ Qtd. de Tarefas 100% Conclu ı ˊ das no Pacote ​ (onde N P ​ é o total de tarefas filhas executáveis do pacote) Avanço Previsto da Linha de Base do Pacote ( Prev P ​ na Data de Corte): Segundo o critério 0/100 do MS Project, uma tarefa da linha de base só é considerada "100% prevista" se a sua Data de Término Previsto ≤ Data de Corte. Se o término estiver no futuro em relação à data de corte, o planejado é 0%. O avanço previsto do pacote é: Prev P ​ = N P ​ Qtd. de Tarefas com T e ˊ rmino Previsto ≤ Data de Corte ​ Avanço Geral do Projeto (Consolidação Ponderada pela Coluna B): Cada pacote tem o seu peso W P ​ (extraído da Coluna B): % Realizado Geral= ∑W P ​ ∑(W P ​ ×Real P ​ ) ​ ×100% % Previsto Geral= ∑W P ​ ∑(W P ​ ×Prev P ​ ) ​ ×100% Desvio de Cronograma ( SV=Schedule Variance): Desvio %=% Realizado Geral−% Previsto Geral Desvio<0 (Vermelho): Atrasado em relação à Linha de Base. Desvio>0 (Verde): Adiantado em relação à Linha de Base. Desvio=0 (Azul): Em dia com a Linha de Base.
